# Herdr 多 Agent 協同練習：由淺至深 6 關

這組練習帶你學會一個工作循環：

> **聰明的主管 AI 派工 → 小模型完成後回報 → 主管檢查 → 不合格就退回修改 → 直到通過**

**你不需要會寫指令，也不需要會寫 prompt。** 你只要用一般的中文說出需求，例如「幫我做一個檢查密碼強不強的功能」。主管 AI（agy）會自動完成以下工作：

1. 把你的話整理成**任務卡**，先給你確認。
2. 自己訂出**驗收標準**（測試或檢查程式）。
3. 寫好派工指示交給**小模型**（OpenCode），不合格就退回修改。
4. 用白話告訴你結果。

每一關只多學一個新概念，最後都有**變化題**：換一句話再做 2～3 次，練到熟為止。對背後的指令有興趣的同學，每關最下方另有「🔧 進階：自己下指令」。

觀念說明請看 👉 [Supervisor 與 SubAgent 終端協同指南](../supervisor-subagent.md)。

---

## 角色分配

| 角色 | 誰 | 做什麼 |
| :--- | :--- | :--- |
| 🧑‍🎓 **你** | 學生 | 用中文說出需求、確認任務卡、回應確認畫面 |
| 👑 **主管（Supervisor）** | agy（Antigravity CLI） | 理解需求、訂驗收標準、派工、驗收、回報 |
| 🛠️ **小模型（SubAgent）** | OpenCode + 免費模型 | 只負責把被交辦的工作做完 |

## 每一關的進行方式

1. 在 `~/herdr-lab` 進入 Herdr，啟動 `agy --mode accept-edits`（見 [準備篇](prepare.md#第三部分和主管-aiagy相處的方式)）。
2. 對 agy 說出這一關的需求。
3. **讀任務卡**，沒問題就回覆「好，開始」。
4. 遇到確認畫面（🔴）時，看清楚再選擇。
5. 觀察窗格的變化，等 agy 回報結果。
6. 回答每關的「想一想」，再做變化題。

## 練習資料夾會長這樣

```text
~/herdr-lab/
├── GEMINI.md        ← 主管 AI 的工作手冊（準備篇下載的）
├── tasks/           ← 主管產生的任務卡（值得一讀！）
├── checks/          ← 主管訂的驗收標準（測試、檢查程式）
└── work/            ← 小模型做出來的成果
```
