# Glow：在終端機裡舒服地讀 Markdown

**Glow** 會把 Markdown 文件排好版顯示在終端機裡：標題有顏色、表格對齊、程式碼有語法顏色。AI 寫出來的規格書、README、筆記，不用打開編輯器就能直接讀。
