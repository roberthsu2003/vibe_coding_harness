# 03-E　E 區：查狀態與設定

> ★ 入門　｜　[← D 區：輸入輔助與切換位置](d-input-nav.md)　｜　[回到 03 斜線指令總覽](../03-slash-commands.md)　｜　下一區：[F 區：做一個自己的斜線指令 →](f-custom-commands.md)

**這一區解決的問題**：「怎麼看目前連線正不正常？怎麼把介面換成喜歡的配色主題？或是下課離開 OpenCode？」

---

## 開始前：建立本節練習資料夾

先完成[課堂練習準備](../../practice/README.md)的工具確認與教材下載，再在**一般終端機**逐行執行：

```bash
python3 ~/terminal-ai-course/practice/prepare.py ~/terminal-ai-labs/opencode/03-e
cd ~/terminal-ai-labs/opencode/03-e
opencode
```

看到目的資料夾已存在時，直接 `cd` 進去接續；要重做則把路徑最後一段改成 `03-e-retry`。本節的程式、筆記與初始 Git commit 都已準備好。

---

## 1. 查狀態與除錯

### `/help`：看怎麼找指令

```text
/help
```

- **結果**：提醒你按 `Ctrl+P` 開啟指令面板查看所有功能。實際操作時，直接打 `/` 或按 `Ctrl+P` 最快。

---

### `/status`：看目前連線狀態

```text
/status
```

- **結果**：顯示模型供應商、MCP 伺服器等連線狀態。覺得哪裡怪怪的時候，先來這裡檢查。快捷鍵：`Ctrl+X` → `S`。

---

### `/stats`：看使用統計

```text
/stats
```

- **結果**：顯示你的 Token 用量圖表、活躍天數與對話次數統計。

---

### `/debug`：看除錯資訊

```text
/debug
```

- **結果**：顯示 OpenCode 版本、作業系統、終端機與目前選用的模型。上課遇到問題向老師或同學求助時，可以把這個畫面的資訊一起附上。

---

## 2. 外觀、設定與更新

### `/themes`：換介面主題配色

```text
/themes
```

- **結果**：列出所有內建配色主題，用上下鍵預覽、選一個就能立刻換上！快捷鍵：`Ctrl+X` → `T`。

---

### `/settings`：開啟設定畫面

```text
/settings
```

- **結果**：開啟互動式設定畫面，用方向鍵 `←`、`→` 即可調整主題、側邊欄、思考過程顯示等選項。

---

### `/reload`：重新載入設定

```text
/reload
```

- **結果**：不用關掉 OpenCode，直接重新讀取設定檔、自訂斜線指令與 Skill。剛新增 `.md` 指令或改了設定卻沒看到時，先跑這一個！

---

### `/plugins`、`/highlights`、`/update`：外掛與版本更新

| 指令 | 用途說明 |
| :--- | :--- |
| `/plugins` | 列出目前已安裝的外掛 |
| `/highlights` | 再次顯示目前這個版本的更新重點 |
| `/update` | 檢查並安裝新版本（畫面上出現 `/update to install v…` 時代表有新版） |

---

### `/exit`：離開 OpenCode

```text
/exit
```

- **結果**：離開 OpenCode 回到終端機。剛才的對話都會自動保留，下次啟動後用 `/sessions` 就能接著做。別名：`/quit`、`/q`，也可以按 `Ctrl+C`。

---

## 每個指令的完整實測流程

先送出 `請讀 README.md，回覆一句用途，不修改。`，確保已有對話；各面板看完按 `Esc` 返回。

| 指令 | 操作與可交付的結果 |
| :--- | :--- |
| `/help` | 依提示按 Ctrl+P，搜尋 diff，找到功能後取消；記錄找到的名稱 |
| `/status` | 記錄已連接供應商與 MCP 數量；沒有 MCP 也可以是 0 |
| `/stats` | 在發出一則訊息前後各看一次，記下統計；背景統計可能延遲，不要求即時增加固定數值 |
| `/debug` | 記下版本、系統與模型名稱，確認與自己環境相符 |
| `/themes` | 記下原主題，選另一個、關閉面板，確認配色改變，再換回原值 |
| `/settings` | 記下側邊欄或工具顯示原值，切換、關閉再重開確認保存，最後還原 |
| `/reload` | 先在 Build 送出「請建立 .opencode/commands/reload-demo.md，frontmatter description 為重載測試，正文為：只回覆『重載成功』」；重載後 /reload-demo 應出現並正確回答。移除檔案再重載，確認消失 |
| `/plugins` | 記下目前外掛名稱或「無」，不必為本題安裝外掛 |
| `/highlights` | 開啟後記下一項更新重點，返回即可 |
| `/update` | 先記錄 /debug 的版本，任務結束後檢查更新；有更新且決定安裝時，依提示安裝、重啟，再 /debug 確認新版。已最新版也算驗收通過 |
| `/exit` | 離開後執行 opencode -c，應接回本節，再 /sessions 確認紀錄仍在 |

**交付**：自行建立 `settings-record.md`，寫下版本、模型、選過的主題、統計觀察與 reload-demo 的結果。不附帳號憑證。

## ✅ 動手練習：換個喜歡的主題配色並查看學習統計

這個練習**完全不用寫程式**，只需 4 步就能打造順眼的練習環境：

| 步驟 | 在對話框輸入 | 觀察重點 |
| :---: | :--- | :--- |
| **1** | `/themes` | 用上下鍵瀏覽不同配色主題，挑一個你最順眼的按 `Enter` 套用 |
| **2** | `/settings` | 看看有哪些介面開關可以調整（按 `Esc` 返回） |
| **3** | `/stats` | 看看今天練習下來累積了多少對話次數與 Token 統計 |
| **4** | `/status` 與 `/debug` | 認識狀態面板與版本資訊畫面，以後遇到問題就知道去哪裡看！ |
