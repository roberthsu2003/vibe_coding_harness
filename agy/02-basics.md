---

## 1. 啟動與離開

在專案資料夾內啟動：

```bash
cd ~/my-project
agy
```

也可以額外加入其他專案目錄到同一個工作空間：

```bash
agy --add-dir ~/shared-library
```

### 離開 CLI

- 輸入 `/exit` 或 `/quit`
- 或連續按下 **`Ctrl+D Ctrl+D`**

---

## 2. 輸入方式

| 輸入方式 | 說明 | 範例 |
| :--- | :--- | :--- |
| **一般文字** | 直接描述需求讓 AI 規劃與執行 | `請幫我檢查 src/ 的代碼風格並加上型別註釋` |
| **`@檔名`** | 引用專案檔案，將檔案脈絡加入對話 | `請看 @src/server.py ，解釋它的路由設計` |
| **`/指令`** | 呼叫斜線指令（Slash Commands） | `/plan`、`/compact`、`/help` |

---

## 3. 三種執行模式（Execution Modes）

`agy` 支援三種不同的代理執行模式，控制 AI 在修改檔案時的自主程度：

| 模式 | 說明 | 適用時機 |
| :--- | :--- | :--- |
| `auto` | 預設模式。代理自主讀取檔案、編寫代碼並在必要時驗證 | 一般功能開發與除錯 |
| `plan` | 規劃模式。只產生架構分析與逐步計畫，不直接修改檔案 | 大型架構重構、事前確認方案 |
| `accept-edits` | 自動接受所有檔案變更 | 信任度高或批次自動修正任務 |

在啟動時指定模式：

```bash
agy --mode plan
```

---

## 4. 常用斜線指令（Slash Commands）

在 `agy` 對話輸入框輸入 `/help` 可以查看目前支援的所有斜線指令。常用的有：

| 斜線指令 | 用途說明 |
| :--- | :--- |
| **`/help`** | 顯示所有可用指令與當前環境資訊 |
| **`/plan`** | 進入深度規劃流程，在動手改代碼前先擬定完整的步驟步驟計畫 |
| **`/compact`** | 壓縮長對話，摘要過去內容以騰出上下文空間（Context Window） |
| **`/goal`** | 啟用長任務專注模式，讓 agent 不達目標不停止，適合自動化夜間修復 |
| **`/schedule`** | 設定單次計時器或排程週期任務（例如定期檢查測試狀態） |
| **`/browser`** | 啟用網頁瀏覽與自動化互動工具 |
| **`/grill-me`** | 讓 AI 對你進行深度技術提問（Interview），釐清邊界條件與規格 |
| **`/boost`** | 啟動深度推理模式，進行多視角分析與嚴格驗證 |

---

## 5. 第一次對話範例

進入 `agy` 後，先讓 AI 探索整個專案：

```text
請閱讀專案的目錄架構與 README，用繁體中文以三點簡要說明專案功能與架構。
先不要修改任何檔案。
```
