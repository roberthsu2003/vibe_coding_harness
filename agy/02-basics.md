## 開始前：建立本節練習資料夾

先完成[課堂練習準備](../practice/README.md)的工具確認與教材下載，再在**一般終端機**逐行執行：

```bash
python3 ~/terminal-ai-course/practice/prepare.py ~/terminal-ai-labs/agy/02
cd ~/terminal-ai-labs/agy/02
agy
```

看到目的資料夾已存在時，直接 `cd` 進去接續；要重做則把路徑最後一段改成 `02-retry`。本節的程式、筆記與初始 Git commit 都已準備好。

## 1. 啟動與離開

在專案資料夾內啟動：

```bash
cd ~/terminal-ai-labs/agy/02
agy
```

### 三種常用的啟動方式

| 指令 | 用途 |
| :--- | :--- |
| `agy` | 開始新對話 |
| `agy -c` | 接續這個資料夾最近一次的對話 |
| `agy -i "幫我看一下這個專案"` | 啟動時直接交代第一個任務，之後繼續對話 |

### 離開

輸入 `/exit`，或連按兩次 `Ctrl+D`。

---

## 2. 四種輸入方式

| 開頭 | 意思 | 範例 |
| :---: | :--- | :--- |
| **直接打字** | 告訴 AI 要做什麼 | `幫我檢查 src/ 有沒有明顯的錯誤` |
| **`@`** | 引用檔案、資料夾、規則或 MCP 工具（輸入時會跳出選單） | `請解釋 @src/server.py 在做什麼` |
| **`/`** | 使用[斜線指令](03-slash-commands.md) | `/plan 加上登入功能` |
| **`!`** | 直接執行終端機指令 | `!git status` |

要換行但還不想送出時，按 `Shift+Enter`、`Alt+Enter` 或 `Ctrl+J`。

---

## 3. 第一次對話

進入 `agy` 後，先讓 AI 認識專案：

```text
請閱讀這個專案的目錄架構和 README，用三點說明這個專案在做什麼。先不要修改任何檔案。
```

AI 要修改檔案或執行指令時，預設會先詢問你。**看懂再同意**，不確定就選擇拒絕，然後問它為什麼要這樣做。

---

## 4. 執行模式

執行模式決定 AI 可以自己做多少事。在對話框按 **`Shift+Tab`** 就能切換。

| 模式 | 修改檔案 | 執行指令 | 適合時機 |
| :--- | :--- | :--- | :--- |
| **default**（預設） | 先問你 | 先問你 | 剛開始學、想看清楚每一步 |
| **plan** | 計畫同意後才改 | 只做唯讀調查，計畫同意後才執行 | 大改動，想先確認做法 |
| **accept-edits** | 自動同意（僅限工作區內） | 先問你 | 信任 AI 的修改，想減少確認 |
| **auto** | 自動同意（僅限工作區內） | 在沙盒中執行，高風險操作仍會詢問 | 熟悉之後，想讓 AI 更自主 |

> [!NOTE]
> `auto` 需要終端機沙盒和個人帳號，企業帳號沒有這個模式。如果切換時沒看到，就是目前的環境不支援。

也可以在啟動時指定模式：

```bash
agy --mode plan
```

> [!TIP]
> 新手建議從 **default** 開始，熟悉之後再試 **accept-edits**。

## 5. 常用快捷鍵

### 基本操作

| 按鍵（英文助記） | 功能 |
| :--- | :--- |
| `Shift+Tab` | 切換執行模式（Cycle Mode） |
| `Ctrl+C` (`Cancel`) 或 `Esc` (`Escape`) | 中斷 AI、關閉選單、清除輸入 |
| `Ctrl+B` (`Background`) | 把正在執行的終端機長指令丟到背景繼續跑（之後可用 `/tasks` 查看與管理） |
| `Tab` | 查看檔案變更和工具執行的細節（View Details） |
| `Ctrl+O` (`Open`) | 展開或收合工具執行的內容 |
| `Ctrl+R` (`Review`) | 開啟產出物審查畫面（Review Artifact），查看計畫和變更 |
| `Ctrl+G` (`Go to Editor`) | 用外部編輯器撰寫比較長的訊息 |
| `Ctrl+L` (`cLear`) | 清除終端機畫面（Clear Screen） |
| `Ctrl+D`（連按兩次，`Disconnect` / `Exit`） | 離開 agy |

### 進階：子代理與 Swarm 快捷鍵（[第 07 站](07-subagents.md)會用到）

| 按鍵（英文助記） | 功能 |
| :--- | :--- |
| `Alt+S` (`Swarm`) | 開啟全螢幕 [Swarm 即時看板](07-subagents.md#7-swarm平行代理協作團隊)（同 `/swarm board`） |
| `Alt+X` (`eXit` / `Close`) | 關閉已完成的 Swarm 底部狀態列 |
| `Alt+J` (`Jump`) | 快速切換焦點到下一個正在等待確認的子代理 |
| `Ctrl+K` (`oK` / `Approve`) | 快速批准狀態列提示中待確認的子代理操作 |

## 完整小範例：讀檔、規劃、修改與驗收

本章素材已包含 `src/server.py`、`README.md`，可直接依序送出：

| 步驟 | 在 agy 輸入框操作 | 預期結果 |
| :--- | :--- | :--- |
| 1 | `請閱讀 README.md，用三點說明這個專案，不要修改。` | 能說出程式與測試指令 |
| 2 | `請解釋 @src/server.py 的 handle_request 會回傳什麼。`（從 `@` 選單選檔案） | 回答「登入成功」並說明呼叫路徑 |
| 3 | `!git status --short` | 尚未修改時無輸出 |
| 4 | 按 `Shift+Tab` 切到 `plan`，輸入 `請規劃把 main.py 的輸出改為「計算結果：4.0」。` | 先提出計畫；尚未核准前 `main.py` 不變 |
| 5 | 審閱計畫並依提示核准 | AI 修改 `main.py` |
| 6 | `/diff` | 看到輸出文字的改動，按 `Esc` 返回 |

**驗收（一般終端機）**：

```bash
python3 main.py
python3 -m unittest discover -s tests -v
```

應印出 `計算結果：4.0`，4 個測試通過。最後切回 `default`，輸入 `/exit`；再在終端機輸入 `agy -c`，應接回剛才對話。用 `agy -i "請讀 README.md 並摘要，不要修改"` 啟動則會先回答再留在對話框。

快捷鍵也能實測：在 AI 修改的工具紀錄按 `Ctrl+O` 展開再收合；輸入框先打兩行文字（用 `Ctrl+J` 換行），確認尚未送出後按 `Esc` 清掉。長指令的 `Ctrl+B` 完整練習見 [03-D](03-slash-commands/d-output.md)。

## ✅ 動手練習

1. 啟動 `agy`，問它這個專案在做什麼。
2. 用 `@` 引用一個檔案，請它解釋。
3. 輸入 `!ls` 看看結果。
4. 按 `Shift+Tab` 切換執行模式，觀察輸入框下方的變化，再切回 `default`。
