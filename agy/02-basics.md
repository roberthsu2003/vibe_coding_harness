# 02　基本操作

> ★ 入門　｜　[← 01 安裝與登入](01-install.md)　｜　[章節首頁](README.md)　｜　下一站：[03 斜線指令 →](03-slash-commands.md)

**這一站你會學到**：啟動與離開 agy、四種輸入方式、執行模式，以及常用快捷鍵。

---

## 1. 啟動與離開

在專案資料夾內啟動：

```bash
cd ~/my-project
agy
```

### 三種常用的啟動方式

| 指令 | 用途 |
| :--- | :--- |
| `agy` | 開始新對話 |
| `agy -c` | 接續這個資料夾最近一次的對話 |
| `agy -i "幫我看一下這個專案"` | 啟動時直接交代第一個任務，之後繼續對話 |

### 離開

輸入 `/exit`，或連按兩次 `Ctrl+D`。

---

## 2. 四種輸入方式

| 開頭 | 意思 | 範例 |
| :---: | :--- | :--- |
| **直接打字** | 告訴 AI 要做什麼 | `幫我檢查 src/ 有沒有明顯的錯誤` |
| **`@`** | 指定檔案，輸入時會出現路徑建議 | `請解釋 @src/server.py 在做什麼` |
| **`/`** | 使用[斜線指令](03-slash-commands.md) | `/plan 加上登入功能` |
| **`!`** | 直接執行終端機指令 | `!git status` |

要換行但還不想送出時，按 `Shift+Enter`、`Alt+Enter` 或 `Ctrl+J`。

---

## 3. 第一次對話

進入 `agy` 後，先讓 AI 認識專案：

```text
請閱讀這個專案的目錄架構和 README，用三點說明這個專案在做什麼。先不要修改任何檔案。
```

AI 要修改檔案或執行指令時，預設會先詢問你。**看懂再同意**，不確定就選擇拒絕，然後問它為什麼要這樣做。

---

## 4. 執行模式

執行模式決定 AI 可以自己做多少事。在對話框按 **`Shift+Tab`** 就能切換。

| 模式 | 修改檔案 | 執行指令 | 適合時機 |
| :--- | :--- | :--- | :--- |
| **default**（預設） | 先問你 | 先問你 | 剛開始學、想看清楚每一步 |
| **plan** | 計畫同意後才改 | 只做唯讀調查，計畫同意後才執行 | 大改動，想先確認做法 |
| **accept-edits** | 自動同意（僅限工作區內） | 先問你 | 信任 AI 的修改，想減少確認 |
| **auto** | 自動同意（僅限工作區內） | 在沙盒中執行，高風險操作仍會詢問 | 熟悉之後，想讓 AI 更自主 |

> [!NOTE]
> `auto` 需要終端機沙盒和個人帳號，企業帳號沒有這個模式。如果切換時沒看到，就是目前的環境不支援。

也可以在啟動時指定模式：

```bash
agy --mode plan
```

> [!TIP]
> 新手建議從 **default** 開始，熟悉之後再試 **accept-edits**。

---

## 5. 常用快捷鍵

| 按鍵 | 功能 |
| :--- | :--- |
| `Shift+Tab` | 切換執行模式 |
| `Ctrl+C` 或 `Esc` | 中斷 AI、關閉選單、清除輸入 |
| `Tab` | 查看檔案變更和工具執行的細節 |
| `Ctrl+O` | 展開或收合工具執行的內容 |
| `Ctrl+R` | 開啟產出物審查畫面，查看計畫和變更 |
| `Ctrl+G` | 用編輯器撰寫比較長的訊息 |
| `Alt+S` | 開啟全螢幕 [Swarm 即時看板](07-subagents.md#5-swarm平行代理協作團隊)（同 `/swarm board`） |
| `Alt+X` | 關閉已完成的 Swarm 底部狀態列 |
| `Alt+J` | 快速切換焦點到下一個正在等待確認的子代理 |
| `Ctrl+K` | 快速批准狀態列提示中待確認的子代理操作 |
| `Ctrl+L` | 清除終端機畫面 |
| `Ctrl+D` | 離開 agy |
