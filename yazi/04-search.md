**這一站你會學到**：在檔案很多的專案裡，快速找到你要的檔案或資料夾。

---

## 1. 四種找檔案的方式

| 方式 | 按鍵 | 適合什麼時候 | 需要的工具 |
| :--- | :--- | :--- | :--- |
| **過濾** | `f` | 目前資料夾檔案很多，只想看名稱包含某些字的 | — |
| **尋找** | `/`（往下）、`?`（往上） | 游標直接跳到名稱符合的檔案；`n` / `N` 跳下一個 / 上一個 | — |
| **依檔名搜尋** | `s` | 檔案在子資料夾深處，不知道在哪 | `fd` |
| **依內容搜尋** | `⇧S` | 記得檔案裡寫了什麼，但不記得檔名 | `ripgrep` |

> 按 `Esc` 取消過濾；搜尋跑太久時，按 `Ctrl+S` 取消。

## 2. 快速跳到別的資料夾

| 按鍵 | 功能 | 需要的工具 |
| :--- | :--- | :--- |
| `⇧Z` | 跳到**常去的**資料夾（輸入幾個字就好，例如 `vibe`） | `zoxide` |
| `z` | 用模糊搜尋選一個資料夾或檔案跳過去 | `fzf` |

> `zoxide` 會記住你常去的資料夾，用得越久越準。

## 3. 分頁：同時開好幾個資料夾

| 想做的事 | 按鍵 |
| :--- | :--- |
| 在目前資料夾開新分頁 | `t` `t` |
| 切換到第 N 個分頁 | `1` ～ `9` |
| 上一個 / 下一個分頁 | `[` / `]` |
| 關閉目前分頁 | `Ctrl+C` |

> 分頁很適合「從 A 資料夾複製檔案到 B 資料夾」：一個分頁開 A，另一個開 B。

## ✅ 動手練習

1. 在專案根目錄按 `f`，輸入 `md`，只顯示 Markdown 檔，再按 `Esc` 取消。
2. 按 `s` 搜尋 `README`，找出所有子資料夾裡的 README。
3. 按 `⇧S` 搜尋某個你記得的字。
4. 按 `t` `t` 開新分頁，用 `1`、`2` 切換。
