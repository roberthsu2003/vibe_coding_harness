# Yazi：在終端機裡看檔案、管檔案

**Yazi** 是一套在終端機裡使用的檔案管理器。不用離開終端機、不用拿滑鼠，就能：

- 用**三欄畫面**瀏覽資料夾，右邊即時**預覽檔案內容**。
- 複製、搬移、改名、刪除檔案，每個動作只要按一個鍵。
- 一鍵**複製檔案路徑**，貼給 AI 當作提示的一部分。
