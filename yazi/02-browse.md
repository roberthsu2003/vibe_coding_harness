# 02　瀏覽與預覽

> ★ 入門　｜　[← 01 安裝](01-install.md)　｜　[章節首頁](README.md)　｜　下一站：[03 檔案管理 →](03-file-ops.md)

**這一站你會學到**：看懂三欄畫面，在資料夾之間移動、開啟檔案、預覽內容。

---

## 1. 三欄畫面

![Yazi 三欄式畫面](assets/yazi-three-column-layout.svg)

| 欄位 | 顯示什麼 | 用途 |
| :--- | :--- | :--- |
| **左欄** | 上一層資料夾 | 知道自己在哪裡 |
| **中欄** | 目前資料夾的內容 | 用游標選檔案 |
| **右欄** | 游標所在項目的**預覽** | 程式碼會有顏色；資料夾會列出裡面的檔案 |

---

## 2. 移動與開啟

| 想做的事 | 按鍵 | 方向鍵 |
| :--- | :--- | :--- |
| 往下 / 往上 | `j` / `k` | `↓` / `↑` |
| 進入資料夾 | `l` | `→` |
| 回上一層 | `h` | `←` |
| 用預設程式開啟檔案 | `Enter`（或 `o`） | — |
| 跳到最上面 / 最下面 | `g` `g` / `⇧G` | — |
| 捲動右側的預覽 | `⇧J` / `⇧K` | — |

> `j k l h` 是 Vim 風格的按鍵，手不用離開打字區。習慣方向鍵也完全沒問題。

---

## 3. 看見隱藏檔

以 `.` 開頭的檔案（例如 `.env`、`.gitignore`、`.worktrees/`）預設看不到。

按 **`.`（句點）** 就會顯示，再按一次又會隱藏。

---

## ✅ 動手練習

1. 在一個專案資料夾執行 `yazi`。
2. 用 `j` / `k` 移動，觀察右欄的預覽變化。
3. 進入一個資料夾（`l`），再回到上一層（`h`）。
4. 停在一個較長的程式檔上，用 `⇧J` 捲動右側預覽。
5. 按 `.` 顯示隱藏檔，找到 `.gitignore`，再按 `.` 隱藏。
